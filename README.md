# ProgramTemplateMaker

This is a small program meant to streamline the start of other new projects in C++.
It takes location and desired binary name as command line arguments and generates a directory hierarchy with some basic starting source files, header files, Makefile, .gitignore, and README.md.

#### Usage

```
programtemplatemaker \
    --location <FILE_PATH> \
    --binary <BINARY_NAME> \
    --remote <GITHUB_REMOTE_URL>
```
